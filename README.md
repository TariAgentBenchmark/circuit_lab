# Circuit Lab

A static classroom circuit-learning prototype for lessons, lab tasks, and simple circuit simulation.

## Quick Start

Download the project files, then double-click `index.html` to open it in a browser.

Online demo:

```text
https://tariagentbenchmark.github.io/circuit_lab/#welcome
```

No installation or setup is required.
